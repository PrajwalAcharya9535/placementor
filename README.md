Placementor 🚀

A smart placement preparation platform for students.

🔹 Features

- 📄 Resume ATS Analysis
- 🧠 Aptitude Test (MongoDB-based questions)
- 💻 Technical Coding Round
- 🎤 HR Interview Simulation
- 📊 Final Score & Selection Status

🔹 Tech Stack

- Frontend: React.js
- Backend: Node.js, Express
- Database: MongoDB

🔹 Modules

1. Resume Upload & Score
2. Aptitude Round
3. Technical Round
4. HR Round
5. Final Result

🔹 How to Run

Backend

cd backend
npm install
npm start

Frontend

cd placementor-frontend
npm install
npm start
